# Labeled evaluation set for masking + Drain clustering (tests/accuracy.rs).
#
# Format: a line starting with "==" opens a group: "== <group id> | <expected pattern>".
# The lines that follow, until the next group, are the messages of that group, in the order
# they are clustered (Drain depends on order). Blank lines and lines starting with "#" are
# ignored. In a message, "\e" stands for the empty message and "\xNN" for a byte (control
# characters). The expected pattern is written as veylog shows it after masking (<NUM>, <IP>,
# <EMAIL>, <PATH>, <URL>, <UUID>, <TIME>) and clustering (<*>). Tokens are split at whitespace,
# so a wildcard always covers a whole token ("[panel.list]" or "$product" become <*>).
#
# "Expected" means the grouping a reader of the report would want: messages that differ only
# in variable data belong together; messages that differ in an exception class, a SQLSTATE
# code, an HTTP status code, an error code or a word that changes the meaning stay apart. The
# set deliberately contains such negative pairs (groups with a "-" suffix). The metrics in
# tests/accuracy.rs report how close the current implementation is; the baseline numbers are
# documented there and in docs/benchmarks.md. All data is fictional.
